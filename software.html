Software

Software

Open-source methods for long-read sequencing analysis. Each repository includes the current code, installation instructions, and documentation.

Cellular context

SniffCell

Uses DNA methylation on native long reads to assign informative molecules to cell types and support cell-type-resolved variant discovery from bulk sequencing.

Repository & documentationPreprint

Haplotype phasing

MethPhaser

Extends sequence-based haplotype phase blocks using allele-specific DNA methylation, adding phasing information in regions with limited heterozygous variants.

Repository & documentationPaper

Rare disease genomics

TBAS

An analysis workflow for Trio-barcoded Adaptive Sequencing, combining phenotype-informed enrichment and long-read analysis of an affected individual and both parents.

Analysis workflowPaper

Sequence alignment

Vulcan

A dual-mode long-read mapping pipeline that combines minimap2 and NGMLR to improve alignment and downstream structural-variant calling.

Repository & documentationPaper

Methylation visualization

methylplotter

Visualization tools for exploring methylation patterns in haplotype-phased BED files and preparing locus-level figures.

Repository & documentation

Tandem-repeat analysis

mTRplotter

Tools for visualizing tandem-repeat read-length distributions and generating locus-specific summary tables from Medaka and TRGT outputs.
